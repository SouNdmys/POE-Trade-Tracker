## What changed

A fix release for the updater, after a real-machine check showed that 1.0.7 could not update
itself to 1.0.8 over a slow, unstable route to GitHub: the check timed out, and the download
died near the end every time.

- **The updater follows the Windows system proxy.** It now honours the same proxy setting your
  browser uses (and `HTTPS_PROXY` if you set it), for both the version check and the download.
  Before, it always made a raw connection, so a machine that reaches GitHub only through a proxy
  or VPN could never update.
- **A manual "check" waits 30 seconds.** The check at launch keeps its 12-second limit so a dead
  network never stalls startup; pressing the button yourself gets the longer wait.
- **The download lands on disk, resumes, and retries.** It is written to
  `updates\pending-update-<tag>.zip.part` as it arrives. If the connection drops, the program
  asks for the rest with an HTTP Range request and continues from where it stopped, up to five
  attempts with short pauses between them. A half-downloaded release survives a restart of the
  program; only parts of other releases are swept.
- **The 30-second cap on the download body is gone.** The previous configuration let the
  "waiting for headers" deadline keep running through the body, which cut every download at
  30 seconds regardless of speed. That is what made 1.0.8 fail at ninety percent. A stalled
  connection is now caught by a per-read 60-second guard instead, and a single attempt may run
  for up to 30 minutes.

**You have to install this one by hand.** The updater that would fetch it is the thing being
fixed, so download the zip below and extract it over your program folder. Settings, calibration
and the database are untouched. Later versions can be installed from inside the program again.

## Install

Create a folder, extract the zip into it, run `ptt-app.exe`. The zip carries no folder of its
own — twelve files arrive as four loose ones plus `assets\` and `licenses\` — so extracting
straight into Downloads scatters them.

Do not extract into `C:\Program Files`. There is no installer and the program cannot elevate
itself, so the updater will refuse to write there.

Updating over an existing install: extract the zip into the folder you already use and let it
overwrite. Your settings, calibration and database are untouched.
