## What changed

This release covers everything since 1.0.5: the hourly ledger that shipped as 1.0.6 in the
source tree but was never published, PoE 1 parity for the Exchange page, and the fixes from the
pre-release review.

**The Exchange page** (official currency-exchange history from `web.poecdn.com`, fetched once
an hour, anonymous and read-only, only while a league name is set):

- The right-hand panel shows the selected currency's hourly ledger: volume and price per hour,
  drawn as bars with the gaps kept as gaps, with a hover readout.
- The table's window chips (24h / 3d / 7d / all) re-rank rows by ledger volume over that window.
- Volume is priced in the settlement currency you configured, and the page says which one.
- PoE 1 works: the PoE 1 hour URL has no realm segment (every PoE 1 fetch used to 404), leagues
  use the short id (`Allflame`, not "Curse of the Allflame"), and the PoE 1 divination cards are
  mapped.
- A failed sync is shown on the page in red, with the reason, instead of only scrolling past in
  the status log. A misspelled league name lists the league names the data actually contains.
- After three consecutive failures the retry backs off to the hourly slot instead of hammering
  the CDN every 30 seconds.
- Hourly detail older than 14 days is folded into daily figures and dropped (Settings → Season &
  storage, "hourly retention").

**Errors reach the screen** — nothing that used to fail silently still does:

- A corrupt `settings.json` is moved aside as `settings.json.corrupt-<stamp>` and reported in red
  on the status line. It used to be overwritten with defaults on the next start.
- "Start watch" refuses to start until the profile's three regions are calibrated, and names the
  Calibrate page. It used to run on factory 2560×1440 coordinates and quietly read nothing.
- A market pulse or daily rollup that fails to load leaves a note on the page it affects.
- A page that fails to read draws in the danger colour, with a human hint for database errors.
- A season that fails to load is an error, not "no season".
- Every crash is written to `panic.log` next to the database before the program exits.

**Pages:**

- The top band always shows the active game and league.
- Watchlist rows carry a freshness light for their newest book.
- Convert routes carry the light of their oldest leg, and the page says how many routes were
  hidden for pricing worse than going direct.
- The radar's verdict and risks columns are gone from the table; both live in the detail panel,
  and the route column got the room.
- One percent rule everywhere: signed for moves, capped at ±999% so a cell stays one line. Large
  amounts follow the interface language (万/亿 or k/M) on every page.
- The main window cannot shrink below the 1180×640 it was laid out for.
- The in-app guide covers the Exchange page, the league-name step and the two new refusals.

## If you had this configured

- **Watch hotkey**: the default is `Ctrl+Alt+F10` in both places it was declared. A value you
  set yourself is kept.
- **Alt+F12 "capture one frame"** is gone. It was never bound to anything; an old settings file
  that still mentions it loads fine.
- **Algorithm numbers → convert sizes** is gone; the built-in 1 / 10 / 100 ladder applies. An
  old settings file that still carries the value loads fine.
- **Exchange hourly retention** defaults to 14 days; hours older than that are folded into
  daily figures and dropped.
- Nothing else you calibrated, tuned or picked changes meaning.

## Install

Create a folder, extract the zip into it, run `ptt-app.exe`. The zip carries no folder of its
own — twelve files arrive as four loose ones plus `assets\` and `licenses\` — so extracting
straight into Downloads scatters them.

Do not extract into `C:\Program Files`. There is no installer and the program cannot elevate
itself, so the updater will refuse to write there.

Updating from inside the app: press check, then install, then close and reopen the program.
Your settings, calibration and database are untouched.
