## What changed

A small fix release for something found on the first real-machine check of 1.0.7.

- **The Exchange page's controls no longer vanish when a sync fails.** In 1.0.7 the red
  "last sync failed" text sat on the same row as the sync / export / window / date controls, and
  a long message (a misspelled league name lists the league names the data actually contains)
  pushed those controls off the right edge of the window. The error now has its own line under
  the controls and wraps; the controls stay put whatever the message length.
- **Saving a league name takes effect at once.** The old error clears the moment you save, and
  if a sync round is running when you save, the program restarts with the new name as soon as
  that round finishes instead of waiting for the next hourly slot. The stale round's verdict is
  discarded, so a "check the league name" message from the old name can no longer land after you
  have corrected it.
- **The league-name warning is bilingual.** "N hours stored but none for this league — check the
  league name · leagues in the data: …" now follows the interface language on the page. The
  status log at the bottom stays English, as before.

For the record: the league name is the whole selection. The official hourly file carries every
league of the game (Standard, Hardcore, the current league, its `HC ` variant, private leagues),
and the program keeps only rows whose league equals the name you typed, character for character.
`Runes of Aldur` is the current softcore league; `HC Runes of Aldur` its hardcore; `Standard` and
`Hardcore` are the permanent leagues.

## Install

Create a folder, extract the zip into it, run `ptt-app.exe`. The zip carries no folder of its
own — twelve files arrive as four loose ones plus `assets\` and `licenses\` — so extracting
straight into Downloads scatters them.

Do not extract into `C:\Program Files`. There is no installer and the program cannot elevate
itself, so the updater will refuse to write there.

Updating from inside the app: press check, then install, then close and reopen the program.
Your settings, calibration and database are untouched.
