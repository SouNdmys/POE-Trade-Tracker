# 灵感存档：暗金蹲价小工具（网页轮询 + 提醒）

> 状态：**未立项**。这不是 POE Trade Tracker 的设计文档，是一个独立小工具的灵感记录。
> 通货主线（官方历史 API + 大雷达）做完之前不动它。
> 记录日期：2026-08-31。接口事实均为当日实测，非道听途说。

## 想解决的事

刷图的时候蹲某件暗金（法血、猎首这种）。程序替我盯着交易网站，
出现满意价格区间的货就弹提醒，我自己切出去买——有缘就买，没缘拉倒。
程序**只看、只提醒**，买永远是人的手在操作。

## 实测的接口事实（2026-08-31）

官方交易网站背后的接口（文档外，但 awakened 系工具用了多年，GGG 默许）：

```
POST https://www.pathofexile.com/api/trade2/search/poe2/<联赛名>
     body: {"query":{"status":{"option":"online"},"name":"Headhunter"},"sort":{"price":"asc"}}
GET  https://www.pathofexile.com/api/trade2/fetch/<逗号分隔的结果id>?query=<搜索id>
```

- **不需要登录**。无 Session、无 Cookie 就能搜索和拉挂单详情。
- **实时**：fetch 返回每条挂单的物品、价格、卖家账号+角色名+在线状态（含 afk）、
  上架时间、以及一句现成的 whisper 私聊语句。
- **限速头明示规则**：`X-Rate-Limit-Ip: 5:10:60,15:60:300,30:300:1800,600:21600:3600`，
  即短线每 10 秒最多 5 次、长线每 6 小时 600 次 ≈ **持续每 36 秒一次搜索**。
  蹲一两件东西绰绰有余；超限只是 429 + IP 冷却，不是封号。
- 网页版自带 Live Search（websocket 推送，秒级），是官方认可的蹲价正道；
  自建轮询的增量是"通知形式合自己习惯 + 能接进自己的估值体系"。

## 关键背景：POE2 的立即购买模式

现在的挂单交易有两种：老式 whisper 问候，和**立即购买**——卖家把货挂在
浮士德/安洁的玩家商店仓库，买家在网页点 travel to hideout，游戏内自动传送到
对方藏身处、自动打开那页仓库、红框锁定看中的那件，点购买即成交，
**不需要卖家在场配合**。这意味着蹲价链条里唯一的人工环节就是
"看到通知 → 切出游戏 → 点两下"，慢了也只是没抢到，不存在谈判失败。

## 设计原则（红线）

- 程序做的只有：读接口、算价格、弹 Windows 通知（+声音）。
- **绝不向游戏发送任何输入**，绝不自动 whisper、自动传送、自动购买。
  GGG 的执法原则是"一次按键一个动作"，碰了游戏输入才有封号风险；
  纯读接口最坏只是 IP 限速。
- 轮询温柔：按限速头预算的一半用（比如 3 个搜索、每个 2 分钟一轮）。
- 预期管理：分钟级轮询抢不过职业狙击手的秒级 live search，
  目标是"价格不错、窗口有几分钟"的单子，不是神单。
